### 1. Is there two-factor authentication?
<Tabs>
    <TabCard label="Yes">
        ```yml
        voucher:
          # The material.
          item: 'diamond_helmet'
          # All options when they right-click it.
          options:
            # The confirmation settings.
            two-factor:
              # If this should be enabled.
              toggle: false
              # The messages to send to confirm.
              message:
                - "{prefix}<gray>Right click again to confirm that you want to use this voucher."
        ```

        <Aside type="note">
            The plugin reads the toggle from `options.two-step-authentication`. If that key is missing, it reads `two-factor.toggle` from the voucher root instead, not from `options`, so the `options.two-factor.toggle` key in the shipped `vouchers/Example.yml` is ignored (upstream bug).

            Players with `crazyvouchers.bypass.2fa` skip the confirmation.
        </Aside>
    </TabCard>
</Tabs>

### 2. My player heads aren't working / Can I use player heads?
<Tabs>
    <TabCard label="My player heads aren't working">
        * You likely have 2 `player` options in your config files, One with the url and one empty so the plugin doesn't know what to do.
    </TabCard>

    <TabCard label="Can I use player heads?">
        * Yes
    </TabCard>
</Tabs>

### 3. My voucher or code stops working after one use with the limiter on
<Tabs>
    <TabCard label="Fix">
        The plugin reads the limit from `options.limiter.limit`, which defaults to `0`.

        The shipped example files use `options.limiter.amount`, which the plugin ignores (upstream bug), so with `toggle: true` the voucher (or code) is blocked after its first use. Set `limit` instead:

        ```yml
        voucher:
          options:
            # Limiter related settings.
            limiter:
              # If this should be enabled.
              toggle: true
              # The max number of uses for the voucher.
              limit: 10
        ```
    </TabCard>
</Tabs>
