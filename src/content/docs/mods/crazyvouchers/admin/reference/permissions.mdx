**This page lists all commands and permissions included in CrazyVouchers.**

## Commands
| Command        | Aliases             |
|----------------|---------------------|
| /crazyvouchers | /vouchers, /voucher |

### Command Permissions
| Command                                                    | Permission Node        | Description                                                | Default |
|------------------------------------------------------------|------------------------|------------------------------------------------------------|---------|
| `/crazyvouchers`                                           | crazyvouchers.access   | Gates the base command, shows the help menu.               | OP      |
| `/crazyvouchers help`                                      | crazyvouchers.help     | Shows the help menu for CrazyVouchers.                     | OP      |
| `/crazyvouchers reload`                                    | crazyvouchers.reload   | Reloads the plugin.                                        | OP      |
| `/crazyvouchers version`                                   | crazyvouchers.version  | Shows the plugin version and git commits.                  | OP      |
| `/crazyvouchers open <page>` (alias: `admin`)              | crazyvouchers.open     | Shows a gui of easy to grab vouchers.                      | OP      |
| `/crazyvouchers types` (alias: `list`)                     | crazyvouchers.types    | Shows a list of voucher codes & items.                     | OP      |
| `/crazyvouchers redeem <code>`                             | crazyvouchers.redeem   | Redeems a voucher code from the `codes` directory.         | OP      |
| `/crazyvouchers give <voucher> <amount> <player> [arg]`    | crazyvouchers.give     | Gives a player a voucher from the `vouchers` directory.    | OP      |
| `/crazyvouchers giveall <voucher> <amount> [arg]`          | crazyvouchers.giveall  | Gives all players a voucher from the `vouchers` directory. | OP      |
| `/crazyvouchers migrate -mt <type>`                        | crazyvouchers.migrate  | Migrates old vouchers/config to the new formats.           | OP      |

#### Migration Types
The values accepted by `/crazyvouchers migrate -mt <type>`:

| Type                 |
|----------------------|
| `VouchersDeprecated` |
| `VouchersNbtApi`     |
| `VouchersSwitch`     |
| `NewItemFormat`      |
| `VouchersColor`      |
| `VouchersRename`     |

### Misc Permissions
| Permission Node            | Description                                                                         | Default |
|----------------------------|-------------------------------------------------------------------------------------|---------|
| crazyvouchers.admin        | Shows all vouchers and codes in tab completion.                                     | OP      |
| crazyvouchers.notify.duped | Notifies you if a duped voucher is used.                                            | OP      |
| crazyvouchers.bypass       | Bypasses the voucher limiter (and voucher cooldown) and the code permission/world checks. Does not bypass a code's limiter or a voucher's permission/world checks. | OP      |
| crazyvouchers.bypass.2fa   | Bypasses the two-factor confirmation when clicking a voucher.                        | OP      |
