<Aside type="note">
    Since 5.2.0, custom items use the `plugin@id` format: `itemsadder@<item_id>`, `nexo@<item_id>`, `oraxen@<item_id>`, `craftengine@<item_id>` or `hmcwraps@<item_id>`.

    Any place you can input `diamond_axe` allows you to use this format.
</Aside>

<Tabs>
    <TabCard label="ItemsAdder">
        <Aside type="tip">
            All identifiers for items can be found via `ItemsAdder/contents` folder

            ```yml
            info:
              namespace: iaalchemy -> this is the namespace.
            items:
              arcane_ring: -> arcane_ring is the identifier.
                enabled: true
                display_name: display-name-arcane_ring
                permission: iaalchemy.items.arcane_ring
                lore:
                  - lore-1-arcane_ring
                  - lore-2-arcane_ring
                resource:
                  material: TOTEM_OF_UNDYING
                  generate: true
                  textures:
                    - item/arcane_ring
               attribute_modifiers:
                 mainhand:
                   movementSpeed:
                     value: 0.1
                     operation: multiply_base
                 offhand:
                   movementSpeed:
                     value: 0.1
                     operation: multiply_base
            ```

            `iaalchemy:arcane_ring` is the combined result needed, used as `itemsadder@iaalchemy:arcane_ring`!
        </Aside>

        `itemsadder@iaalchemy:arcane_ring` can be used in any section that asks for a material such as `diamond_axe`.

        ### Example
        ```yml
        voucher:
          # The custom item from ItemsAdder.
          item: "itemsadder@iaalchemy:arcane_ring"
        ```
    </TabCard>

    <TabCard label="Nexo">
        <Aside type="tip">
            All identifiers for items can be found via `/nexo give [item]`, or `nexo_defaults/items` folder

            ```yml
            forest_axe: -> forest_axe is the identifier.
              itemname: Forest Axe
              material: NETHERITE_AXE
              Pack:
                model: nexo:item/nexo_tools/forest_axe
                custom_model_data: 1000
            ```
        </Aside>

        `nexo@forest_axe` can be used in any section that asks for a material such as `diamond_axe`.

        ### Example
        ```yml
        voucher:
          # The custom item from Nexo.
          item: "nexo@forest_axe"
        ```
    </TabCard>

    <TabCard label="Vanilla" icon="warning">
        <Aside type="note">
            ```yml
            voucher:
              # Any generic component for the Item.
              components:
              # The item model, Mojang introduced this in 1.21.4... this replaces custom model data!
              # Set this to blank for it to do nothing.
              item-model:
                # The namespace i.e. nexo
                namespace: "nexo"
                # The key i.e. emerald_helmet
                key: "emerald_helmet"
            ```
        </Aside>
    </TabCard>
</Tabs>
