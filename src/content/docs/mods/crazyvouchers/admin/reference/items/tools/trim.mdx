<Aside type="note">
    The map-style `items:` layout (`"1":` with `material:` and `settings:`) only applies when `root.use-different-items-layout: true` is set in `config.yml` (default `false`). You can migrate existing vouchers with `/crazyvouchers migrate -mt NewItemFormat`. Otherwise the map-style `items:` section is ignored.
</Aside>

<Aside type="tip">
    Armor Trims can be used on everything but Leather Armor.
</Aside>

<Tabs>
    <TabCard label="Default">
      <Tabs>
        <TabCard label="Display">
            ```yml
            # The voucher section.
            voucher:
              # The item material.
              item: "diamond_helmet"
              # The trim to display on the voucher item.
              display-trim:
                material: amethyst
                pattern: bolt
            ```
        </TabCard>

        <TabCard label="Item">
            ```yml
            # The voucher section.
            voucher:
              # The item material.
              item: "diamond_helmet"
              # The items section.
              items:
                # The name of the item, good for identification internally and externally.
                "1":
                  # The item material.
                  material: "diamond_helmet"
                  # Per item settings.
                  settings:
                    # The trim to display on the helmet.
                    trim:
                      pattern: bolt
                      material: amethyst
            ```
        </TabCard>
      </Tabs>
    </TabCard>

    <TabCard label="Legacy">
        <Aside>
            There is no "Display" under `Legacy`, because the "Display" in `Default` is sufficient.
        </Aside><br/>

        <Tabs>
        <TabCard label="Item">
            ```yml
            # The voucher section.
            voucher:
              # The item material.
              item: "diamond_helmet"
              # The items section.
              items:
                - "item:diamond_helmet, trim:bolt!amethyst"
            ```
        </TabCard>
