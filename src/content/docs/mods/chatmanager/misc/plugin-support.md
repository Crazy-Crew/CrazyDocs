title: Plugin Support
---
Chat Manager works on its own, every plugin below is optional and only adds extra features.

**Information**
Vault and a permissions plugin such as LuckPerms are only needed for per-group chat formats, ChatManager uses Vault (chat + permission services) to look up each players primary group. Without them, everyone uses the default chat format.

An in-depth explanation can be found on the chat format page [here](/mods/chatmanager/guides/chat/formatting/).
