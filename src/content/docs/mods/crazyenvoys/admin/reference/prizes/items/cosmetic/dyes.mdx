<Aside type="caution">
    *Warning, The prize example assumes you know other options must be added for a Prize to function*
    *If not, I recommend you read the remaining documentation*

    *This configuration can be applied to Leather Armor, Filled Map, and other dyeable items liked Tipped Arrows*
    - Submit a suggestion if there is a dyeable item that is missing.
</Aside>

<Tabs>
    <TabCard label="Color">
        ```yml
        # The prizes section.
        Prizes:
          # The name of the prize.
          "1":
            # The items section.
            Items:
              # Uses a color name.
              - "Item:leather_chestplate, Color:green, Amount:1"
        ```
    </TabCard>
    <TabCard label="RGB">
        ```yml
        # The prizes section.
        Prizes:
          # The name of the prize.
          "1":
            # The items section.
            Items:
              # Uses red,green,blue values. Do not put spaces between the numbers.
              - "Item:leather_chestplate, RGB:229,164,229, Amount:1"
        ```
    </TabCard>
</Tabs>
