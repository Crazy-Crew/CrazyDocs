**This page lists all placeholders included in CrazyEnvoys.**

### Placeholders

<Tabs>
    <TabCard label="PlaceholderAPI">
        | Placeholder                 | Description                                                                            |
        |-----------------------------|----------------------------------------------------------------------------------------|
        | `%crazyenvoys_cooldown%`    | `Shows the cooldown until the next envoy.`                                             |
        | `%crazyenvoys_clock%`       | `Shows the clock time (HH:mm:ss) the next envoy starts at.`                            |
        | `%crazyenvoys_time_left%`   | `Shows how much time is left on the current envoy.`                                    |
        | `%crazyenvoys_envoys_left%` | `Shows how many envoys are left.`                                                      |
        | `%crazyenvoys_envoys_time%` | `If envoys.grace-period.toggle is enabled, shows how long until players can claim the envoy.` |
    </TabCard>
</Tabs>
