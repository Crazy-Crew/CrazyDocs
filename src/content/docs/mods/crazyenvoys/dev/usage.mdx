<Aside type="note">
    Full examples are still being written. For now, here are the Bukkit events CrazyEnvoys fires, all in `com.badbones69.crazyenvoys.api.events`.
</Aside>

### Events
| Event                  | Cancellable | Description                                                                                                                                                                     |
|------------------------|-------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `EnvoyStartEvent`      | Yes         | Fired when an envoy starts. `getReason()` returns an `EnvoyStartReason`: `FORCED_START_PLAYER`, `FORCED_START_CONSOLE`, `AUTO_TIMER`, `SPECIFIED_TIME`, `FLARE` or `CUSTOM`. `getPlayer()` is only set for `FORCED_START_PLAYER` (a player running `/envoy start`). It is null for every other reason, including `FLARE`. |
| `EnvoyEndEvent`        | No          | Fired when an envoy ends. `getReason()` returns an `EnvoyEndReason`: `FORCED_END_PLAYER`, `FORCED_END_CONSOLE`, `OUT_OF_TIME`, `ALL_CRATES_COLLECTED`, `NO_LOCATIONS_FOUND`, `RELOAD`, `SHUTDOWN` or `CUSTOM`. |
| `EnvoyOpenEvent`       | Yes         | Fired when a player claims an envoy. Gives the player, block/location, `Tier` and the picked prizes, which you can replace with `setPrize(List<Prize>)`.                         |
