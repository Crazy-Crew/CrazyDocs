**This page lists all commands and permissions included in CrazyAuctions.**

## Commands
| Command          | Aliases                 |
|------------------|-------------------------|
| `/crazyauctions` | /crazyauction, /ah, /ca |

### Auction Permissions
| Command                                       | Permission Node                                    | Description                                                                      | Default |
|-----------------------------------------------|----------------------------------------------------|----------------------------------------------------------------------------------|---------|
| `/ca`                                         | crazyauctions.access                               | Opens up the auction house.                                                      | true    |
| `/ca help`                                    | crazyauctions.access                               | Shows all available commands.                                                    | true    |
| `/ca expired`                                 | crazyauctions.access                               | Opens up the player's cancelled and expired items list.                          | true    |
| `/ca collect`                                 | crazyauctions.access                               | Same as `/ca expired`.                                                           | true    |
| `/ca listed`                                  | crazyauctions.access                               | Opens up the player's current listings, selling and bidding.                     | true    |
| `/ca view <player>`                           | crazyauctions.view                                 | Shows the list of items being sold by the searched player.                       | true    |
| `/ca sell <price> [amount]`                   | crazyauctions.sell                                 | Add the item currently in your hand to the selling section of the auction house. | true    |
| `/ca bid <price> [amount]`                    | crazyauctions.bid                                  | Add the item currently in your hand to the bidding section of the auction house. | true    |
| `/ca reload`                                  | crazyauctions.reload                               | Reloads all the files. Also granted by the `crazyauctions.admin` wildcard.       | OP      |
| `/ca force_end_all`                           | crazyauctions.force-end-all                        | Force ends all listed items. Also granted by the `crazyauctions.admin` wildcard. | OP      |

`[amount]` is how many items to take from the stack you are holding (1-64). If left out, the whole stack is listed.

### Misc Permissions
| Permission Node      | Description                                                                                                              | Default |
|----------------------|--------------------------------------------------------------------------------------------------------------------------|---------|
| crazyauctions.bypass | Bypasses the `sell.#` / `bid.#` listing limit. This is the only check that uses it: price limits and the blacklist still apply. | false   |
| crazyauctions.force-end | Allows a player to force-cancel a listing by shift-clicking it in the auction house. `crazyauctions.admin` also allows this. | OP      |
| crazyauctions.player.* | Wildcard: grants `crazyauctions.bid`, `crazyauctions.sell`, `crazyauctions.access` and `crazyauctions.view`.            | false   |
| crazyauctions.admin  | Wildcard: grants `crazyauctions.reload`, `crazyauctions.force-end-all` and `crazyauctions.bypass`.                        | false   |

<Aside type="caution">
    `crazyauctions.sell.#` and `crazyauctions.bid.#` set how many items a player can list. Replace `#` with a number, such as `5`, to allow 5 active listings.

    - Both limits start at **0**: a player with no `sell.#` node cannot list with `/ca sell`, and a player with no `bid.#` node cannot list with `/ca bid`.
    - The limits are separate: `sell.#` (checked on `/ca sell`) counts only the player's selling listings, and `bid.#` (checked on `/ca bid`) counts only their bidding listings.
    - If a player has more than one node of the same kind, the highest number wins.
    - Players with `crazyauctions.bypass` skip the limit.
</Aside>
