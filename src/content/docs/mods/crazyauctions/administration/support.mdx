### Economy Plugins
<Aside type="caution">
    **Vault is required.** CrazyAuctions will not load without it, and you also need an economy plugin that hooks into Vault.
</Aside>

### Item Plugins
<Aside type="note">
    Only **Oraxen** is supported: GUI buttons in `config.yml` can use an Oraxen item ID as their `Item`.
</Aside>

<Tabs>
    <TabCard label="Oraxen">
        <a href="https://www.spigotmc.org/resources/%E2%98%84%EF%B8%8F-oraxen-custom-items-blocks-emotes-furniture-resourcepack-and-gui-1-18-1-20-4.72448/">
            <Image src={Spigot} alt="Spigot Logo"/>
        </a>
    </TabCard>
</Tabs>

### Other Plugins
<Aside type="note">
    PlaceholderAPI placeholders are parsed in single-line plugin messages (`messages.yml`) sent to players. GUI item names and lore are not parsed. CrazyAuctions does **not** provide its own PlaceholderAPI expansion.
</Aside>
